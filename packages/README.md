# Packages

Shared libraries consumed by applications.

| Package | Import | Purpose |
|---------|--------|---------|
| `common/` | `@vsp/common` | Shared constants and types |
| `config/` | `@vsp/config` | Environment variable helpers |
| `logger/` | `@vsp/logger` | Structured logging utilities |

TypeScript path aliases are configured in `tsconfig.base.json`.
