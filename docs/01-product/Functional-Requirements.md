## Scope & Conventions

<!-- To be completed during the architecture phase -->

### Requirement ID Format

`FR-<domain>-<number>` (e.g. `FR-VOICE-001`)

### Priority Levels

| Level | Definition |
|-------|------------|
| P0 | Must have — launch blocker |
| P1 | Should have — near-term release |
| P2 | Could have — future release |
| P3 | Won't have (this phase) |

### Requirement Template

| Field | Description |
|-------|-------------|
| ID | Unique requirement identifier |
| Title | Short descriptive title |
| Description | Detailed behavior |
| Priority | P0–P3 |
| Acceptance Criteria | Verifiable conditions |
| Dependencies | Related requirements or systems |
